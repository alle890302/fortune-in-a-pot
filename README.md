One kind, funny fortune for a houseplant, written by a tiny Python program.

> You will lean toward the sun so far this week the gardener must turn your pot, and you will pretend it was your idea.

Run `python3 main.py` — it writes the fortune to `/output/entry.txt` (117 characters, one line).
